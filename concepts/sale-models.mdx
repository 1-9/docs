title: "Sale Models"
description: "The four ways a domain can be acquired on your marketplace and what each shows to buyers."
---

Every domain has a **Sale Model** that determines what CTAs (call-to-action buttons) visitors see on its page. Set the sale model in the **Pricing & Sale Terms** section of the domain edit form.

## The four models

### Make an Offer _(default)_

Visitors see an offer form. They enter a name, email, and bid amount.

Use this when you want to start a negotiation without naming a price, or when you're not sure of the domain's value yet.

- No price required
- Offer submissions land in **Transactions → Offers**
- You can counter, accept, or reject from the admin panel

### Buy it Now

Visitors see a fixed price and a buy button.

<Info>
  Direct checkout is coming in a future release. Until then, **Buy it Now** domains show the price and fall back to an inquiry form — visitors can reach out to complete the purchase manually.
</Info>

- Requires a **Price** to be set
- If no price is set, the page shows "Make Offer" instead of the price

### BIN + Make Offer

Visitors see both a fixed price and an offer form.

Use this when you want to set a ceiling while still accepting lower bids.

<Info>
  Same note as Buy it Now — direct checkout is not yet available. The price is displayed, and the offer form works normally.
</Info>

- Requires a **Price** to be set for the BIN button to appear
- The offer form is always visible regardless of whether a price is set

### Contact Only

Visitors see only an inquiry form. No price, no offer form.

Use this for premium domains where you want to qualify buyers before revealing a price, or for domains you're not actively selling but are open to inquiries on.

- **Show Inquiry Form** checkbox has no effect in this mode — the inquiry form always shows
- Submissions land in **Transactions → Inquiries**

---

## The Show Inquiry Form checkbox

Available on **Buy it Now** and **BIN + Make Offer** only. When checked, an inquiry form is added below the main CTA. Use it when you want to let buyers ask a question without committing to a full offer.

---

## Summary

| Model | Price shown | Buy button | Offer form | Inquiry form |
|---|---|---|---|---|
| Make an Offer | — | — | Always | Optional |
| Buy it Now | If set | Coming soon | — | Optional |
| BIN + Make Offer | If set | Coming soon | Always | Optional |
| Contact Only | — | — | — | Always |

<Note>
  The "Optional" entries in the Inquiry form column correspond to the **Show Inquiry Form** checkbox. Check it to add an inquiry form alongside the main CTA.
</Note>
