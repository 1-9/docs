title: "Sale Models"
description: "Compare the four sale models in Domainer Engine — Buy Now, Make an Offer, combined, and Inquiry-only — and what each shows to buyers on a domain page."
---

Every domain has a **Sale Model** that determines what CTAs (call-to-action buttons) visitors see on its page. Set the sale model in the **Pricing & Sale Terms** section of the domain edit form.

## The four models

### Make an Offer _(default)_

Visitors see an offer form. They enter a name, email, and bid amount.

Use this when you want to start a negotiation without naming a price, or when you're not sure of the domain's value yet.

- No price required
- Offer submissions land in **Transactions → Offers**
- You can counter, accept, or reject from the admin panel

### Buy it Now

Visitors see a fixed price and a Buy Now button that takes them off-site to complete payment.

<Info>
  The Buy Now button is an outbound link, not an on-site checkout — it opens the **default payment provider's** purchase URL (configured in [Payment Settings](/configuration/payment-settings)), with the domain name and price substituted in. There's no webhook or automated status change: mark the domain **Sold** yourself once the sale closes.
</Info>

- Requires a **Price** to be set, and a default provider configured in Payment Settings with Buy It Now enabled
- If no price is set, the default provider isn't eligible for this domain (see **Linked Marketplace** in Payment Settings), or the domain's own **Hide Buy Now Button** checkbox is on, the button is hidden and the page falls back to an inquiry form
- If no price is set at all, the page shows "Make Offer" instead of the price

### BIN + Make Offer

Visitors see both a fixed price/Buy Now button and an offer form.

Use this when you want to set a ceiling while still accepting lower bids.

<Info>
  Same Buy Now eligibility rules as above apply here — the button only shows when a price is set and the default provider is eligible for this domain. The offer form works independently either way.
</Info>

- Requires a **Price** to be set for the Buy Now button to appear
- The offer form is always visible regardless of whether a price is set

### Contact Only

Visitors see only an inquiry form. No price, no offer form.

Use this for premium domains where you want to qualify buyers before revealing a price, or for domains you're not actively selling but are open to inquiries on.

- **Show Inquiry Form** checkbox has no effect in this mode — the inquiry form always shows
- Submissions land in **Transactions → Inquiries**

---

## The Show Inquiry Form checkbox

Available on **Buy it Now** and **BIN + Make Offer** only. When checked, an inquiry form is added below the main CTA. Use it when you want to let buyers ask a question without committing to a full offer.

---

## The Hide Buy Now Button checkbox

Also available on **Buy it Now** and **BIN + Make Offer**, right below Show Inquiry Form. Check it to suppress the Buy Now button on this one domain only — regardless of price, Payment Settings, or provider eligibility. Marketplace buttons and the offer form are unaffected.

Use it for a domain you want off the market temporarily (under negotiation elsewhere, price under review) without switching its sale model or clearing its price. It also silences the admin-only BIN warning banner for that domain, since hiding the button was a deliberate choice, not a misconfiguration.

## Summary

| Model | Price shown | Buy Now button | Offer form | Inquiry form |
|---|---|---|---|---|
| Make an Offer | — | — | Always | Optional |
| Buy it Now | If set | If eligible | — | Optional |
| BIN + Make Offer | If set | If eligible | Always | Optional |
| Contact Only | — | — | — | Always |

<Note>
  The "Optional" entries in the Inquiry form column correspond to the **Show Inquiry Form** checkbox. Check it to add an inquiry form alongside the main CTA.
</Note>

## The "Listed On" marketplace panel

Independent of the sale model above, the domain page can also show a "Listed On" panel linking out to any marketplace checkboxes you've enabled on the domain (Afternic, Sedo, Atom — see [Domains](/concepts/domains)). This panel's prominence is controlled site-wide by **Marketplace Listings Display** in [Payment Settings](/configuration/payment-settings):

| Setting | Behavior |
|---|---|
| **Default** | Full panel with heading and colored buttons, always shown regardless of Buy Now. |
| **Compact** | Collapses to a single inline sentence ("Also listed on Afternic, Sedo, and Atom.") — but only once the Buy Now button is actually showing on that domain. Otherwise falls back to the full panel. |
| **Hidden** | Never shown, unconditionally. |
