---
title: "Page Builder Blocks"
description: "Reference for all 23 page builder blocks in Domainer Engine — hero, features, FAQ, CTA, domain grids, and more — used on pages, templates, and the homepage."
---

Blocks are the building material for every page. Add them from the **Sections** field on any page or template, drag to reorder, and configure each one independently.

Every block has an optional **Spacing** field (top and bottom padding: none / xs / sm / md / lg / xl / 2xl) that controls the vertical rhythm of the page.

---

## Content blocks

### Banner

A full-width notification strip. Optionally dismissible.

| Field | Options / Notes |
|---|---|
| **Content** | Rich text message |
| **Style** | info · success · warning · promo |
| **Dismissible** | Visitor can close the banner |
| **CTA Button** | Optional — enable, then set label and URL |

---

### Text

A rich text content section.

| Field | Options / Notes |
|---|---|
| **Content** | Rich text — headings, lists, links, inline images |
| **Max Width** | narrow · normal · wide |
| **Use Background** | Wraps the text in a surface card with border and padding |

### CTA

A call-to-action section with one or two buttons.

| Field | Options / Notes |
|---|---|
| **Heading** | Required |
| **Text** | Supporting copy |
| **Background** | default · primary · muted |
| **Primary Button** | Label and URL — required |

### Features

A feature list in cards, list rows, or icon-only layout.

| Field | Options / Notes |
|---|---|
| **Heading** | Optional |
| **Style** | cards · list · icons-only |
| **Items** | Each item: image (optional), icon (Lucide icon name, shown when no image), title, description |

To use an icon, type the Lucide icon name in the **Icon** field — for example `Zap`, `Globe`, `CheckCircle`. Icons are pulled from the lucide-react library.

| Field | Options / Notes |

## Hero block

### Hero

The full-width page hero — large heading, background image, CTA button, and an optional AI domain matcher chat widget.

The Hero block is available on the **Homepage** and on **CMS Pages**. It is not available on other templates.

| Field | Options / Notes |
|---|---|
| **Heading** | Required |
| **Subheading** | Optional |
| **Background Image** | Optional background |
| **CTA** | Optional button — label and URL |
| **AI Matcher** | Enable to show a chat widget that suggests domains. Fields: enabled, title, description, placeholder, content, system prompt |

<Note>
  The AI Matcher widget requires AI to be configured in **Settings → AI**. It uses its own system prompt field — customize it to describe how the matcher should respond.
</Note>
