title: "Appearance Settings"
description: "Style your marketplace — choose light or dark theme, accent colors, header and body fonts, border radius, and the default domain catalog card layout."
---

**Settings → Appearance** controls the visual style of the public site. Changes apply immediately after saving — no redeploy needed.

## Color Theme

Choose between **Dark** and **Light**. This is the base theme for the entire site.

Once you pick a theme, a second selector appears to fine-tune the background tone:

**Dark theme backgrounds:**

| Option | Hex |
|---|---|
| Abyss | `#0c0c0f` |
| Midnight | `#0d0d0d` |
| Onyx | `#0f0f0f` |
| Obsidian | `#111111` |
| Slate | `#131520` |
| Charcoal | `#1a1a1a` |
| Graphite | `#1c1c1e` |

**Light theme backgrounds:**

| Option | Hex |
|---|---|
| Cream | `#fffdf7` |
| Pearl | `#fafafa` |
| Parchment | `#f8f8f6` |
| Mist | `#f4f4f5` |
| Linen | `#f5f0e8` |
| Stone | `#f2ede6` |
| Silver | `#efefef` |

## Font

Nine font options available. All are loaded via Google Fonts and render at the same weights:

DM Sans, Inter, Geist, Plus Jakarta, Outfit, Bricolage Grotesque, Syne, Space Grotesk, Urbanist.

## Border Radius

Controls the roundness of cards, buttons, and input fields across the site:

| Option | Radius |
|---|---|
| Sharp | 0 px |
| Subtle | 4 px |
| Rounded | 8 px |
| Soft | 12 px |
| Pill | 16 px |

## Domain Catalog Default View

Sets whether the domain inventory opens in **Grid** (cards) or **List** (compact rows) by default. Visitors can toggle between the two views — this just controls the initial state.

## Colors

Two accent color pickers control the key highlight colors on the site:

| Field | Where it appears |
|---|---|
| **Accent Color** | Price display, badges, highlighted numbers. Default: green `#22c55e`. |
| **CTA Button Color** | Background of primary action buttons (Buy Now, Make Offer, Inquire). Default: near-black `#111827`. |

Both fields use a color picker — click the swatch to open it, or type a hex value directly.
