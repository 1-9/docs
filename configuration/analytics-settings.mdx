**Settings → Tracking** controls two independent analytics systems. You can use one, both, or neither.

## Built-in analytics

The platform includes its own privacy-first analytics tracker. It records page views, visitor counts, referrer sources, countries, device types, marketplace-link clicks, and Buy Now clicks — all server-side, without cookies. Visits arriving through a [parked domain](/domains/parking) redirect are tracked under a distinct "Parking Redirect" source rather than being lumped in with direct traffic.

| Field | Description |
|---|---|
| **Enable own analytics tracker** | Master switch. On by default. |

No setup required beyond the toggle. Data is visible in the **Analytics** section of the admin dashboard and on individual domain pages.

**Privacy characteristics:**
- No cookies used
- Visitor identity is derived from a salted hash — no raw IP addresses stored
- GDPR-compliant by design — no cookie banner needed for built-in analytics alone

Results appear in the admin Dashboard and in the Analytics tab on each domain's edit page.

## Google Analytics 4

Connect a GA4 property to get Google's reporting alongside the built-in tracker.

| Field | Description |
|---|---|
| **Enable Google Analytics 4** | Loads the GA4 script after visitor consent. |
| **GA4 Measurement ID** | Your property ID, e.g. `G-XXXXXXXXXX`. Found in Google Analytics → Admin → Data Streams. |

### Cookie banner

When GA4 is enabled, a **Consent Mode** setting controls whether — and to whom — a cookie banner is shown before the GA4 script loads:

| Mode | Behavior |
|---|---|
| **Always show** (default) | Every visitor sees the banner before GA4 loads. Unchanged from prior behavior. |
| **EU visitors only** | The banner only gates GA4 for visitors detected in the EU, EEA, or UK — everyone else gets GA4 immediately, no banner. Detection is server-side, from the request's country; if the country can't be determined, it defaults to showing the banner (the safe fallback). |
| **Off (no banner)** | GA4 loads for every visitor immediately, with no consent prompt at all. |

<Warning>
  **Off** loads GA4 with no consent gate for anyone — a real GDPR/ePrivacy risk if you have EU visitors. The admin panel shows a warning next to this setting when it's selected. Only use it if you have another consent mechanism in place, or GA4 usage that genuinely doesn't require consent in your jurisdiction.
</Warning>

When the banner does show, customize its text to match your site's tone:

| Field | Default |
|---|---|
| **Banner text** | `We use analytics to improve your experience.` |
| **Accept button** | `Accept` |
| **Decline button** | `Decline` |

If the visitor declines, the GA4 script is never loaded. The built-in analytics tracker is unaffected in every mode — it runs regardless of consent since it uses no cookies.
